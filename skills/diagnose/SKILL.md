# Diagnose

Run `node ${CLAUDE_PLUGIN_ROOT}/scripts/control.mjs diagnose` from the project root. Report plugin and Node versions, platform support, hook JSON validity, route and state health, transaction status, and official Codex companion availability. Do not claim installed behavior that was not tested.
